# PQ Design · Color

Light: workspace #F4F6F9, panel #FFFFFF, raised #E8EDF4, text #182230, secondary #536175, accent #205BCD. Dark: workspace #151A21, panel #1E2631, raised #293545, text #F2F5FA, secondary #AFBED0, accent #8BB5FF. Status uses success/warning/error/info with text. Accent buttons use a separately paired foreground; never white text on the pale dark-mode accent. High contrast strengthens text and boundaries. System/Light/Dark are persistent user choices.
