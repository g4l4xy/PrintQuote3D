# PQ Design · Components

PQButton: primary/secondary/destructive mapped to native buttons. PQToolbar/PQFilterBar: bounded tool layer, wrap or horizontally scroll controls at narrow widths. PQSidebar: selected state, labels and keyboard activation. PQInspector: secondary pane with explicit identity; collapses to single-pane details. PQCard: only independent summaries, not every field. PQSearchField: labeled local search with clear/reset. PQStatusBadge: text+symbol, never color alone. PQMetric/PQTechnicalValue: title/value/unit with tabular figures. PQTable: bounded/lazy rows, persistent columns, visible focus. PQEmptyState: explanation+appropriate action. PQErrorState: issue, retained-data assurance only when true, retry/details. PQSectionHeader: consistent title and optional explanation.
