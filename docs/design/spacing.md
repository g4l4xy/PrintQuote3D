# PQ Design · Spacing

PQSpacing: hair=2, xs=4, sm=8, md=12, lg=16, xl=20, section=24, page=32, wide=40, touch=48, hero=64. Compact page insets use lg; desktop section. Logical points/dp, not physical pixels. Row padding and column widths are independent from type scaling. PQRadius: control=6, panel=12, floating=20, pill=999. No nested rounded panels around individual form fields.
