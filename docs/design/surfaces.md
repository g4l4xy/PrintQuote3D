# PQ Design · Surfaces

PQMaterial levels: workspace 0, panel 1, raised 2, tools/inspector 3, modal 4. Data panels remain opaque. Elevation relies first on value separation and a fine border; floating tools may add a shallow shadow. Tables have a stable opaque header, neutral rows and selected-state indication. Avoid shadows on every row. PQBorder normal=1 logical unit, emphasized=2. High contrast promotes boundaries.
